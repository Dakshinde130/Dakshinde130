## &nbsp;Things I've Built

Here are four projects I'm proud of. Click any of them to see the code.

<br/>

### 🎯 &nbsp;[Anikator](https://github.com/Dakshinde130/anikator)
A guessing game like Akinator. You think of an anime character, and it asks you questions until it figures out who you picked. It uses probability to guess smart, not random. I built the whole thing on my own.

`Python` &nbsp; `Bayesian Logic` &nbsp; `Decision Trees` &nbsp; `React`

<br/>

### 👗 &nbsp;[SmartStyle AI](https://github.com/Dakshinde130/SmartStyle-AI-based-Family-Wardrobe-and-Outfit-Recommendation-System)
An app that helps you manage your wardrobe and suggests outfits to wear. It uses computer vision to look at your clothes, has secure OTP login, and saves everything to the cloud. It works for one person, a couple, or a whole family.

`Python` &nbsp; `Computer Vision` &nbsp; `React` &nbsp; `Supabase`

<br/>

### 🔄 &nbsp;[SkillSwap](https://github.com/Dakshinde130/skillswap)
A simple website where students teach each other. You share a skill you know, and you learn a skill from someone else. No money, just trading what you're good at. I made it because I think classmates can learn a lot from each other.

`Python` &nbsp; `Streamlit` &nbsp; `Pandas` &nbsp; `JSON`

<br/>

### 🍳 &nbsp;[Recipe Generator](https://github.com/Dakshinde130/recipe-generator)
A Java app that gives you recipe ideas. You tell it what you like or what you have, and it pulls recipes from an online API. I focused on keeping the code clean and easy to add to later.

`Java` &nbsp; `APIs` &nbsp; `Object-Oriented Programming`
